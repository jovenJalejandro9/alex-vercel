# Guía de estilo · Vercel-inspired (Alex)

Dirección visual tomada del estudio de vercel.com (nov 2026). No usa el triángulo ni logos de Vercel.

## Carácter
Infraestructura esencial / rigor del desarrollador. Geist, monocromo, metadatos mono, CTAs black/white.

## Color
| Uso | Valor |
|---|---|
| Fondo | `#fafafa` / surface `#fff` |
| Texto | `#171717` |
| Muted | `#4d4d4d` |
| Bordes | `#ebebeb` |
| Link puntual | `#0070f3` |
| Contacto | invertido `#171717` / `#ededed` |

## Tipografía
Geist Sans + Geist Mono (libre, vercel.com/font). Títulos peso 400–500, tracking −0.04em. Mono en fechas, chips, eyebrows.

## Motivos
Hairlines, radios 6–8 px, CTAs píldora negro/blanco, sin arcoíris ni falsa terminal. Sin mesh Stripe.

## CV A4
Monocromo, fechas mono, bordes finos, nombre Geist 500.
